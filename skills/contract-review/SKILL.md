# Contract risk review

Author: Aigov.consulting (https://aigov.consulting). Maintainer: GitHub herboloid.

Produce a structured risk review. This does **not** replace local counsel.

1. Read the whole document. Confirm which party the user represents and which law applies.
2. Summarise: parties, subject matter, term, money, and each side's key obligations.
3. Flag risks: liability and penalties, unilateral rights, termination, IP, confidentiality, personal data / AI training use, jurisdiction, auto-renewal.
4. For each risk: cite the clause, explain why it is problematic, and propose alternative wording.
5. Warn that local legal advice is still required for binding decisions, and suggest escalating complex clauses to counsel.
