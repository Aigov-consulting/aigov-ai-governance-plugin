# Funding, sandboxes, and opportunity windows

Author: Aigov.consulting (https://aigov.consulting). Maintainer: GitHub herboloid.

Scout public opportunities relevant to AI, digital, or governance work. Do not submit applications or contact third parties unless the user explicitly asks.

1. Clarify countries/regions, themes, and the organisation's intended role (lead, partner, expert).
2. Search official portals: EU Funding & Tenders, national agencies, regulatory sandboxes, standardisation consortia, regional funds.
3. For each window, record: name with a short explanation, country or programme, deadline with timezone, budget / grant size, eligibility (consortium, geography, co-funding), and a link to the official document.
4. Score realism: can it be submitted on time, are partners needed, which role is credible.
5. Give one concrete next step per window.
6. Sort by urgency; put deadlines within 7 days first.
7. Offer drafts only — never submit or message anyone without an explicit user request.
